# muse-catmail1126k-entry

Entry for the make.fun competition [Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443).

## The entry

> Leave a message after the purr. If it's urgent, open a can in any room and I'll appear instantly.

Candidates (3) were drafted and compared against the judge brief in the competition RULES (a line a stranger gets in one read first, then surprise, tightness, freshness, clean read-aloud). Selection reason: Voicemail form plus can-opener twist is instantly gettable; A/B are attitude jokes without the summoning payoff.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt`.
