# muse-catmail1126k-entry

A one-joke entry built for the make.fun contest [Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443).

## What the program does

Executing `main.py` produces a single file, `entry.txt`, holding the greeting quoted below. The script relies on nothing beyond the Python 3 standard library, never reaches out to the network, and yields the identical bytes on every run.

## About the greeting

> Leave a message after the purr. If it's urgent, open a can in any room and I'll appear instantly.

Three drafts were weighed against the priorities spelled out in the contest RULES: a stranger should grasp the joke on first reading, after which surprise, brevity, novelty, and how cleanly the line reads aloud decide the ranking. This draft won because it wears the familiar voicemail formula while the can-opener summons gives it a payoff the two attitude-only alternatives lacked.
